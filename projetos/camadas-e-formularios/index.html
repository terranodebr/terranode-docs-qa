Camadas e formulários do projeto

Camadas e formulários do projeto¶

Cada projeto escolhe as próprias camadas e os próprios formulários. Com isso, a equipe recebe só o que importa para aquele trabalho: um mapa com o contexto certo e os formulários certos para cada pessoa. O aplicativo fica simples e o pacote offline fica pequeno, mesmo que a organização acumule muitos dados e formulários com o tempo.

As camadas dão contexto ao mapa que a equipe vê no app: limites, estradas, imagens, pontos já conhecidos. Os formulários são o que a equipe preenche a cada coleta. Os dois se definem no assistente do projeto e podem ser alterados depois. Para criar o projeto em si, veja Criar um projeto.

Quem pode¶

Quem pode editar o projeto (permissão de editar e ser criador ou gestor do projeto, veja Papéis e permissões) pode adicionar e remover camadas e formulários. Todos os membros da organização veem as abas Dados Vetoriais e Formulários do projeto. Para carregar a lista de formulários e membros no assistente, a pessoa também precisa poder criar projetos.

Camadas¶

De onde vêm as camadas¶

Uma camada do projeto é uma fonte de dados de um catálogo. Você pode usar:

  • os catálogos da sua organização, veja Catálogos e fontes de dados;
  • os catálogos públicos, veja Catálogos públicos e dados públicos.

O assistente só oferece catálogos que têm fontes de dados e, quando o projeto já tem área de cobertura, só os que intersectam essa área. Por isso vale definir a área antes de escolher as camadas. Qualquer tipo de fonte serve: pontos, linhas, polígonos, raster ou tabelas sem geometria.

Adicionar, ordenar e remover¶

  1. No passo Camadas do assistente (ou em Adicionar do catálogo, na aba Dados Vetoriais, que abre a mesma tela em uma janela), escolha Adicionar.
  2. Encontre o catálogo com Buscar catálogo. Cada catálogo mostra quantas fontes tem; marque fontes uma a uma ou use Selecionar todas as camadas de ....
  3. Escolha Concluir. As camadas entram na lista, e o mapa de pré-visualização ao lado mostra o resultado.

Na lista, a camada de cima é desenhada por cima das outras. Arraste com Reordenar para mudar a ordem, use Mostrar / Ocultar para conferir a composição e Remover para tirar uma camada. Cada camada precisa de um nome único no projeto. O rodapé resume "N camadas de M catálogos"; o projeto pode seguir sem camadas.

Regras que você vai encontrar:

  • Sem estilo próprio. A camada herda o estilo da fonte de dados no catálogo. Para mudar cores, rótulos ou zoom mínimo, edite o estilo na página do catálogo, veja Estilos e legenda. Uma fonte cujo estilo ainda não foi publicado fica fora do pacote até ser publicada.
  • Uma camada que o mapa não consegue mostrar aparece com a nota "Sem pré-visualização" ou "Pré-visualização indisponível"; ela continua no projeto.
  • Remover uma camada não apaga nada no catálogo.
  • Toda mudança nas camadas fica registrada como Camadas alteradas na aba Atividade e, em um projeto em andamento, agenda uma nova versão do pacote, veja Quando o pacote é gerado.

A aba Dados Vetoriais¶

A aba Dados Vetoriais da página do projeto mostra o mapa com todas as camadas e uma tabela Camada para ligar e desligar cada uma e ver sua legenda. A marca Zoom N+ avisa que a camada só aparece a partir daquele nível de aproximação. A seção Enviadas neste projeto traz as camadas que chegam do campo (trajetos, coletas e mídias), explicadas em Acompanhar o projeto.

Formulários¶

Vincular formulários ao projeto¶

No passo Formulários do assistente (ou em Gerenciar formulários, na aba Formulários), marque os formulários da organização que a equipe vai usar. Use Buscar formulário para encontrar um pelo nome. Dali mesmo você pode:

  • escolher Novo formulário: o que está marcado é salvo, o construtor abre e, ao terminar, você volta para onde estava (o assistente ou a janela Formulários do projeto) com o formulário já marcado;
  • escolher Duplicar em um formulário existente, com o mesmo vai e volta.

Como criar e editar formulários está em Criar e editar formulários.

Quem recebe cada formulário¶

Para cada formulário marcado, o botão Selecionar coletores abre a lista de quem o recebe no app. Só coletores da equipe podem ser registrados; a lista fica vazia enquanto o projeto não tem coletores. A regra completa de quem coleta o quê:

Papel no projeto Formulários que recebe no app
Gestor do projeto e Revisor Todos os formulários do projeto, sem precisar de registro
Coletor Só os formulários em que foi registrado
Membro da organização fora da equipe Nenhum

Os papéis de projeto estão em Equipe do projeto. Se um coletor sai da equipe ou muda de papel, seus registros nos formulários são removidos junto.

Remover um formulário¶

Desmarcar um formulário (ou excluir o formulário na organização) tira o vínculo com o projeto e os registros de coletores. As coletas já recebidas continuam guardadas no projeto; nada é apagado. Um aparelho que já havia baixado o formulário ainda consegue enviar o que coletou com ele, porque o servidor aceita respostas de qualquer formulário entregue àquele aparelho, veja Coletas, mídias e sincronização.

A aba Formulários¶

A aba Formulários lista cada formulário do projeto e, em Atribuído a, as pessoas registradas nele.

O que vai para o app¶

  • As camadas do projeto vão dentro do pacote offline, recortadas pela área de cobertura, com o estilo herdado da fonte. Veja Pacotes offline.
  • Os formulários não ficam no pacote: cada pessoa recebe os seus quando o app baixa o pacote, na revisão mais recente de cada formulário. Alterar um formulário já em uso tem regras próprias, veja O que muda depois da primeira coleta.
