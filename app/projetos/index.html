Projetos e pacotes no celular¶

A lista de projetos no aplicativo mostra o que foi configurado no web app e o que já está no aparelho. Antes de sair a campo, ela deixa claro o que está baixado, o que precisa ser atualizado e o que ainda não tem pacote, para que ninguém chegue ao local sem o mapa e os formulários.

A aba Projetos lista os projetos em andamento da sua organização e mostra, para cada um, se o aparelho já tem o pacote offline. Baixar o pacote é o que permite abrir o mapa e coletar sem conexão. O que entra no pacote e quando o servidor o gera estão em Pacotes offline.

Todo membro vê os mesmos projetos em andamento, independentemente do papel. O que muda é o conteúdo do pacote: cada pessoa recebe só os formulários atribuídos a ela, conforme Camadas e formulários do projeto.

Estados de um projeto na lista¶

Cada cartão mostra a miniatura da área, o nome do projeto, um estado e, quando há, uma ação.

Estado O que significa Ação no cartão
Pendente O servidor tem um pacote pronto e o aparelho ainda não o baixou Baixar projeto
Sem pacote disponível O projeto está em andamento, mas ainda não há pacote (sem área definida ou pacote em geração) Nenhuma; não abre
Atualização pendente O aparelho tem o pacote, e o servidor tem uma versão mais nova Atualizar Projeto; o projeto abre e aceita sessão de campo com a versão atual
Sincronizado O aparelho tem a versão mais recente do pacote Iniciar sessão de campo
Encerrado O projeto foi encerrado no web app (ou não aparece mais na lista do servidor), mas o aparelho tem o pacote Abre só para consulta; Enviar dados se houver algo pendente

Projetos encerrados ficam depois dos projetos em andamento. Projetos em rascunho nunca aparecem no aplicativo.

Projetos não saem do aparelho

Não há como remover um projeto, seu pacote ou suas coletas do aplicativo. Um projeto encerrado continua listado e aberto para consulta. Isso garante que coletas ainda não enviadas nunca se percam.

Baixar um pacote¶

  1. Toque Baixar projeto no cartão (ou Baixar Todos no alto da lista para enfileirar todos os pacotes disponíveis). No primeiro download o Android pede permissão para notificações.
  2. O cartão mostra Baixando… NN% com uma barra de progresso, e uma notificação acompanha o download. Você pode fechar o aplicativo: o download continua em segundo plano.
  3. Quando termina, o cartão passa a Sincronizado e o botão Iniciar sessão de campo aparece.

Regras do download:

  • Um projeto por vez; os demais esperam na fila na ordem em que foram pedidos.
  • Tocar no cartão durante o download cancela e volta ao estado anterior.
  • O download retoma de onde parou se a conexão cair ou o aplicativo for fechado: só os arquivos que faltam são baixados, e cada um é verificado.
  • Arquivos que o aparelho já tem de outra versão não são baixados de novo.
  • Antes de começar, o aplicativo confere o espaço livre. Se faltar, o cartão mostra "Espaço insuficiente. Libere X MB para baixar este projeto."

Outras mensagens de falha no cartão, sempre com Tentar novamente:

Mensagem Causa
Você não tem permissão para baixar este projeto Você não faz parte da equipe do projeto
Este projeto não está mais disponível O projeto foi encerrado ou arquivado enquanto você baixava
Não foi possível baixar o projeto. Tente novamente. Falha de rede ou arquivo corrompido após três tentativas

Quando o download termina, o servidor é avisado e o Gestor passa a ver seu pacote como baixado no cartão Equipe agora do projeto. Esse aviso é reenviado até ser aceito, mesmo que você fique offline por um tempo.

Atualizar um pacote¶

Quando a equipe muda camadas, formulários ou a área do projeto, o servidor gera uma nova versão e o cartão passa a Atualização pendente. Toque Atualizar Projeto. Enquanto a atualização baixa, a versão antiga continua funcionando, inclusive em sessão de campo; a troca só acontece quando todos os arquivos novos estão no aparelho.

Os formulários nunca são apagados do aparelho. Se um formulário sai do projeto, a seção dele na aba Coletas fica marcada como Não coletado mais, e as coletas já feitas continuam visíveis e são enviadas normalmente.

Trabalhar offline¶

Sem conexão, a lista mostra apenas os projetos que o aparelho já tem, sem estado no cartão, e cada um aceita Iniciar sessão de campo. Nada é perdido: a lista é atualizada sozinha quando a conexão volta, quando você reabre a aba ou quando o aplicativo volta ao primeiro plano.

Se o servidor responder com erro, a última lista conhecida é mantida e aparece "Não foi possível atualizar a lista de projetos" com Tentar novamente.

Telas vazias:

  • Nenhum projeto ativo: você está online e a organização não tem projeto em andamento com você na equipe.
  • Nenhum projeto no aparelho: você está offline e nunca baixou um pacote.

Enviar dados a partir do cartão¶

Quando um projeto tem coletas ou mídias ainda não enviadas, o cartão mostra o botão Enviar dados, em qualquer estado, inclusive Encerrado. Ele faz o mesmo que o botão do mapa; o funcionamento está em Enviar dados.

Ver os detalhes de um projeto¶

Abrindo um projeto baixado, a aba Projeto mostra o que o aparelho tem:

  • Projeto: descrição, tipo, prazo, Versão do pacote e Baixado em.
  • Mapa: área (em ha ou km²), se o mapa base está Incluído ou Não incluído e a lista de camadas.
  • Formulários: os formulários atribuídos a você e a revisão de cada um. Se um formulário foi adicionado depois do download, ele chega com a próxima atualização do pacote.
  • Equipe: membros do projeto e papel de cada um, com (você) no seu nome. A equipe só aparece após uma atualização da lista com conexão.

Essa aba mostra apenas o que está no aparelho. Mudanças feitas no web app depois do download só aparecem após atualizar o pacote ou a lista.
