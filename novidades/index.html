Novidades¶

O que mudou no terranode a cada versão, na plataforma web e no aplicativo de campo.

27 de outubro de 2026¶

Primeira edição: reúne o que chegou à plataforma e ao aplicativo de campo entre 28 de agosto e 27 de outubro de 2026.

Destaques¶

Conta e organização¶

Membros e convites Web CLI/API

Convide pessoas por e-mail, acompanhe os convites pendentes e gerencie os membros da organização pela tela de Membros ou pelo tn. Contas novas confirmam o e-mail antes do primeiro acesso. Saiba mais.

Papéis e permissões Web Android

O que cada pessoa vê e pode fazer, na web e no aplicativo, segue o papel dela na organização e no projeto. Saiba mais.

Dispositivos registrados Web Android

Cada coletor registra o celular que usa em campo, e o gestor pode revogar um dispositivo a qualquer momento. Saiba mais.

Busca e tema escuro Web

A busca no topo encontra catálogos, fontes de dados, projetos, formulários e pessoas, e cria um formulário novo direto dali. O seletor na barra superior alterna entre tema claro e escuro.

Catálogos¶

Importar dados Web

Envie arquivos vetoriais, planilhas CSV com colunas de coordenadas e rasters para um catálogo e acompanhe o processamento de cada arquivo em tempo real. Saiba mais.

Página da fonte de dados Web

Cada fonte de dados tem sua página, com mapa, tabela de atributos e configurações. Uma fonte pode ser duplicada para servir de base a outra. Saiba mais.

Estilos e legenda Web

Símbolo único ou classificações, marcadores para pontos, rótulos em linhas e polígonos, faixa de zoom de cada estilo e estilos para rasters, com legenda no mapa. Para dados vetoriais, a plataforma sugere estilos a partir dos atributos. Saiba mais.

Dados públicos Web

Catálogos públicos mantidos pela terranode e atualizados automaticamente: SIGMINE, unidades de conservação (CNUC), terras indígenas (FUNAI) e áreas quilombolas (INCRA). Estão disponíveis para todas as organizações, somente para leitura. Saiba mais.

Usar os dados em outras ferramentas CLI/API

As fontes de dados são publicadas via OGC API Features e podem ser abertas no QGIS, no ArcGIS e em outras ferramentas. Saiba mais.

Formulários¶

Criar e editar formulários Web

Monte formulários no construtor, com campos condicionais e o estado de salvamento sempre visível. Um formulário pode ser copiado ou gerado a partir das colunas de uma fonte de dados. Saiba mais.

Novos tipos de campo Web Android

Código de barras, hora, consulta por localização, localização do envio, foto, assinatura, vídeo e áudio. Saiba mais.

Modelos de formulário Web

Modelos da organização e modelos prontos baseados em fontes oficiais, listados na aba Templates. Saiba mais.

Importar do Survey123 Web

Importe formulários do Survey123 a partir do arquivo XLSForm. Saiba mais.

Projetos¶

Criar um projeto Web CLI/API

O assistente guia a definição da área de cobertura (desenhada no mapa ou importada de um arquivo), das camadas, dos formulários e da equipe. Depois de criado, cada seção do projeto é editada no próprio lugar. O projeto pode ser finalizado e reaberto. Saiba mais.

Equipe do projeto Web

Defina gestores, revisores e coletores de cada projeto e quais formulários cada pessoa coleta. Saiba mais.

Pacotes offline Web Android

O projeto vira um pacote offline com as camadas vetoriais e raster, um mapa base aberto e o enquadramento inicial da área. A aba Pacotes mostra a composição e o andamento de cada versão. Saiba mais.

Acompanhar o projeto Web

A Visão Geral mostra coletas, dias de campo e equipe, com um mapa que exibe trajetos, coletas e mídias à medida que chegam. A aba Coletas permite revisar cada coleta, e a aba Atividade registra o que aconteceu no projeto, com exportação. Saiba mais.

Lista de projetos Web

Veja os projetos em tabela ou em cartões, com a miniatura da área de cada um.

Dados de campo¶

Número da coleta Web Android

Cada coleta recebe um número por projeto e formulário, como RDO-DNIT097-00139, que aparece na web e no aplicativo. Saiba mais.

Aplicativo de campo¶

Projetos e pacotes no celular Android

Entre com a conta da organização e veja seus projetos com o estado do pacote e a miniatura da área. O pacote baixa em segundo plano e é atualizado automaticamente pelo Wi-Fi quando o projeto muda. Saiba mais.

Coletar no campo Android

Preencha os formulários criados na web sobre o mapa do projeto, em sessões de campo que gravam o trajeto. Os dados de cada usuário ficam guardados de forma criptografada no celular. Saiba mais.

Enviar dados Android

O botão Enviar dados no cartão do projeto manda coletas, trajetos e mídias para o servidor, com o progresso no cartão e no mapa. Saiba mais.

Integrações¶

ArcGIS Web

Conecte uma conta ArcGIS, escolha as camadas e importe vetores e rasters. A simbologia e os rótulos do ArcGIS acompanham os dados. Saiba mais.

Google Sheets Web

Traga planilhas do Google Sheets como fontes de dados. Saiba mais.

Sincronização agendada Web

Sincronize várias camadas de uma vez ou agende a sincronização de cada uma. Saiba mais.

Desenvolvedores¶

Linha de comando tn e chaves de API CLI/API

Crie chaves de API da organização e use o tn para gerenciar catálogos, membros, projetos, camadas e formulários do projeto. Saiba mais.

Melhorias e correções¶

Catálogos¶

  • Web Importações de rasters e de tabelas vetoriais grandes ficaram mais estáveis.
  • Web Shapefiles sem a codificação de caracteres declarada são lidos corretamente.
  • Web O catálogo de uma integração excluída não mostra mais o link para ela.
  • Web Os números dos estilos aparecem com no máximo duas casas decimais.

Formulários¶

  • Android Formulários minimizados mantêm as respostas até serem enviados ou descartados.
  • Android Campos de texto começam com letra maiúscula.

Projetos¶

  • Web A área de cobertura aceita pontos, linhas e polígonos com defeitos de geometria.

Aplicativo de campo¶

  • Android O mapa aceita toques ao lado dos botões de camadas e de localização.
  • Android Ao trocar de usuário no celular, os projetos, rascunhos e sessões do usuário anterior não aparecem mais.
  • Android A coleta ficou mais fluida, e o GPS pausa quando o aplicativo vai para segundo plano.

Desenvolvedores¶

  • CLI/API A OGC API Features pagina os itens por cursor, responde mais rápido em tabelas grandes e usa o tipo application/geo+json.
